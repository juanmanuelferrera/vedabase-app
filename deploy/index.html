macOS Installation Instructions

When you first try to open the app, macOS will show a dialog saying "macOS cannot verify that this app is free from malware" with buttons "Move to Trash", "Open Anyway", and "Done".

What to do:

  1. DO NOT click "Move to Trash"
  2. Click "Open Anyway" (the middle button)
  3. The app will open and macOS will remember it's safe

Alternative: Terminal command

If the above doesn't work, open Terminal and run:

xattr -cr /Applications/Vedabase.app

This removes the quarantine flag that macOS adds to downloaded apps. Then open Vedabase normally.

Why does this happen? This app is not signed with an Apple Developer certificate. It's completely safe and open source — you can review the entire code on GitHub.

Android Installation Instructions

Since this APK is not from the Google Play Store, Android will ask you to allow installation from unknown sources.

What to do:

  1. Download the APK file
  2. Open the downloaded file
  3. When prompted, tap "Settings" then enable "Allow from this source"
  4. Go back and tap "Install"

Install as a Web App (PWA)

You can install Vedabase directly from the browser — no download needed. It works offline once installed.

iPhone / iPad (Safari):

  1. Open app.bhaktiyoga.es/app in Safari
  2. Tap the Share button (square with arrow)
  3. Scroll down and tap “Add to Home Screen”

Android (Chrome):

  1. Open app.bhaktiyoga.es/app in Chrome
  2. Tap the three-dot menu (top right)
  3. Tap “Add to Home screen” or “Install app”

Desktop (Chrome / Edge):

  1. Open app.bhaktiyoga.es/app
  2. Click the install icon in the address bar (or menu → “Install Vedabase”)
